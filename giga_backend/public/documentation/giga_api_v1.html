Introduction

Welcome to the Giga Logistics API. This API allows businesses to integrate on-demand delivery services directly into their applications. You can programmatically create orders, track shipments, and receive real-time status updates.

Authentication

The Giga API uses Bearer Token authentication. You must include your API Key in the Authorization header of every request. 

Authorization: Bearer YOUR_API_KEY

You can generate and manage your API keys from the Giga Business Dashboard.

Base URL

https://giga-backend.com/api/v1

Rate Limit: 60 requests per minute.

Create Order

Creates a new delivery request. The fare is calculated automatically based on distance and vehicle type.

POST /orders

Parameters

Field Type Required Description
pickup_address string Yes Full address for pickup
pickup_lat float Yes Latitude of pickup location
pickup_lng float Yes Longitude of pickup location
dropoff_address string Yes Full address for delivery
dropoff_lat float Yes Latitude of delivery location
dropoff_lng float Yes Longitude of delivery location
vehicle_type string Yes Bike, Van, or Truck
service_tier string Yes Standard, Priority, or Saver
recipient_phone string Yes Phone number of the recipient
description string No Details about the package

Response

{
  "status": "success",
  "message": "Order placed successfully...",
  "data": {
    "order_id": 1024,
    "tracking_number": "TRK-883920",
    "fare": 1200.50,
    "status": "pending",
    "security_code": "X7Y2Z9"
  }
}

Swift (iOS) Integration

Copy and paste this helper class to quickly integrate Giga API into your iOS app. 

import Foundation

struct GigaDeliveryRequest: Encodable {
    let pickup_address: String
    let pickup_lat: Double
    let pickup_lng: Double
    let dropoff_address: String
    let dropoff_lat: Double
    let dropoff_lng: Double
    let vehicle_type: String // "Bike", "Van", "Truck"
    let service_tier: String // "Standard", "Priority"
    let recipient_phone: String
    let description: String?
}

class GigaAPI {
    static let shared = GigaAPI()
    private let apiKey = "YOUR_API_KEY" // Replace with your key
    private let baseURL = "https://giga-backend.com/api/v1"

    func createOrder(request: GigaDeliveryRequest, completion: @escaping (Result<[String: Any], Error>) -> Void) {
        let url = URL(string: "\(baseURL)/orders")!
        var urlRequest = URLRequest(url: url)
        urlRequest.httpMethod = "POST"
        urlRequest.setValue("Bearer \(apiKey)", forHTTPHeaderField: "Authorization")
        urlRequest.setValue("application/json", forHTTPHeaderField: "Content-Type")

        do {
            urlRequest.httpBody = try JSONEncoder().encode(request)
        } catch {
            completion(.failure(error))
            return
        }

        URLSession.shared.dataTask(with: urlRequest) { data, response, error in
            if let error = error {
                completion(.failure(error))
                return
            }
            
            guard let data = data else { return }
            
            do {
                if let json = try JSONSerialization.jsonObject(with: data) as? [String: Any] {
                    completion(.success(json))
                }
            } catch {
                completion(.failure(error))
            }
        }.resume()
    }
}

// Usage Example
let request = GigaDeliveryRequest(
    pickup_address: "123 Main St",
    pickup_lat: 6.5244,
    pickup_lng: 3.3792,
    dropoff_address: "456 Broad St",
    dropoff_lat: 6.4544,
    dropoff_lng: 3.4192,
    vehicle_type: "Bike",
    service_tier: "Standard",
    recipient_phone: "+2348000000000",
    description: "Documents"
)

GigaAPI.shared.createOrder(request: request) { result in
    switch result {
    case .success(let response):
        print("Order Created: \(response)")
    case .failure(let error):
        print("Error: \(error)")
    }
}
